# Data

`data/processed/library_combined.csv` is the Phase 1 canonical processed dataset for this portfolio project.

Large raw simulation sweep files are excluded from normal GitHub because they are generated artefacts and may be too large for a lightweight public repository.

The labels and targets in this project are simulation-derived from thermodynamic modelling outputs. They should not be described as wet-lab validated biological labels.

`reports/results/ml_predictions.csv` is an output artefact from model scoring and must not be used as training input.
