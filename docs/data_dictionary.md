# Data Dictionary

This dictionary covers the canonical public dataset and generated reporting artefacts. The most important rule is that observed simulation target columns are not inference features.

## File Overview

| File | Role | Training input? | Notes |
|---|---|---:|---|
| `data/processed/library_combined.csv` | Canonical processed candidate library | Yes, after feature extraction | Contains metadata, design inputs, and thermodynamic simulation-derived targets. |
| `reports/results/ml_predictions.csv` | Generated prediction/reporting artefact | No | Contains predictions plus observed simulation targets for reference. Must not be used as model input. |
| `reports/results/ml_topk_diverse_clean.csv` | Generated clean shortlist | No | Contains ranked candidates after diversity and QC filtering. |
| `reports/results/ml_order_sheet.csv` | Generated practical order sheet | No | Contains ordering/export fields for the clean shortlist. |

## `data/processed/library_combined.csv`

| Column | Meaning | Category | Available at inference time? | Exclude from model input? |
|---|---|---|---:|---:|

| `seq` | RNA candidate sequence. | metadata / input source | Yes | No, transformed into sequence-derived features. |
| `len` | Stored sequence length. | metadata | Yes | No, but the canonical feature extractor recalculates sequence length from `seq`. |
| `rbs_start` | RBS start coordinate used for window features. | input feature source | Yes | No. |
| `rbs_end` | RBS end coordinate used for window features. | input feature source | Yes | No. |
| `extra_pairs` | Design parameter from candidate generation. | input feature | Yes | No. |
| `pGC` | Design-level GC parameter from candidate generation. | input feature | Yes | No. |
| `loop_len` | Design loop length parameter. | input feature | Yes | No. |
| `closed_low` | Simulated low-temperature closed-state measure. | simulation-derived target | No | Yes. |
| `open_midhi` | Simulated openness measure in the mid/high target range. | simulation-derived target | No | Yes. |
| `open_high` | Simulated high-temperature openness measure. | simulation-derived target | No | Yes. |
| `T50` | Simulated temperature where openness is near 50 percent. | simulation-derived target / regression target | No | Yes. |
| `slope70` | Simulated slope around 70 C. | simulation-derived target / regression target | No | Yes. |
| `slope_max` | Supporting simulation output. | simulation-only output | No | Yes. |
| `reentrant_pen` | Supporting simulation penalty/output. | simulation-only output | No | Yes. |
| `score` | Supporting simulation/design score. | simulation-only output | No | Yes. |
| `curve` | Stored simulated openness curve values. | simulation-only output / plotting source | No | Yes. |

## Engineered Features

The model does not consume every raw column directly. `src/thermoswitch/features.py` builds the canonical feature matrix from inference-available fields:

| Feature family | Source columns | Category | Notes |
|---|---|---|---|
| Sequence length | `seq` | input feature | Recalculated from sequence text. |
| GC fraction | `seq` | input feature | Fraction of G/C bases in the sequence. |
| Design metadata | `extra_pairs`, `pGC`, `loop_len` | input feature | Numeric design parameters. |
| Dinucleotide frequencies | `seq` | input feature | Frequency vector for all 16 RNA dinucleotides. |
| Trinucleotide frequencies | `seq` | input feature | Frequency vector for all 64 RNA trinucleotides. |
| RBS-window one-hot features | `seq`, `rbs_start`, `rbs_end` | input feature | Fixed-length local sequence encoding around the RBS window. |

Leakage guard:

- Target columns such as `closed_low`, `open_midhi`, `open_high`, `T50`, and `slope70` must not enter the feature matrix.
- Output columns such as `p_pass`, `t50_pred`, `slope70_pred`, and `rank` must not enter the feature matrix.

## Simulation-Derived Label

The binary pass/fail label is created in `src/thermoswitch/labels.py` from:

| Source column | Role in label |
|---|---|
| `closed_low` | Candidate must meet the configured low-temperature closed-state threshold. |
| `open_midhi` | Candidate must meet the configured target-range openness threshold. |
| `open_high` | Candidate must meet the configured high-temperature openness threshold. |
| `T50` | Candidate must fall within the configured T50 target band. |
| `slope70` | Candidate must meet the configured minimum slope at 70 C. |

This label is thermodynamic simulation-derived, not experimentally validated.

## `reports/results/ml_predictions.csv`

This file is generated by:

```text
scripts/predict_candidates.py
```

| Column | Meaning | Category | Available at inference time? | Exclude from model input? |
|---|---|---|---:|---:|
| `id` | Candidate identifier. | metadata | Yes | Not used as numeric input. |
| `seq` | RNA sequence. | metadata / input source | Yes | No, if transformed by the feature extractor. |
| `len` | Sequence length in the output file. | metadata | Yes | No, but canonical features recalculate length from `seq`. |
| `p_pass` | Predicted probability of meeting the simulation-derived pass specification. | prediction output | Generated by model | Yes. |
| `t50_pred` | Predicted T50. | prediction output | Generated by model | Yes. |
| `slope70_pred` | Predicted slope at 70 C. | prediction output | Generated by model | Yes. |
| `closed_low` | Observed simulation-derived target copied for reporting/reference. | simulation-derived target | No | Yes. |
| `open_midhi` | Observed simulation-derived target copied for reporting/reference. | simulation-derived target | No | Yes. |
| `open_high` | Observed simulation-derived target copied for reporting/reference. | simulation-derived target | No | Yes. |
| `T50` | Observed simulation-derived target copied for reporting/reference. | simulation-derived target | No | Yes. |
| `slope70` | Observed simulation-derived target copied for reporting/reference. | simulation-derived target | No | Yes. |

Important: `ml_predictions.csv` is an output artefact. It must not be used as a training input because it contains model outputs and observed simulation targets.

## `reports/results/ml_topk_diverse_clean.csv`

This file is generated by:

```text
scripts/make_shortlist.py
```

| Column | Meaning | Category | Available at inference time? | Exclude from model input? |
|---|---|---|---:|---:|
| `rank` | Final clean shortlist rank. | shortlist field | Generated by shortlist logic | Yes. |
| `id` | Candidate identifier. | metadata | Yes | Not used as numeric input. |
| `seq` | RNA sequence. | metadata / input source | Yes | No, if transformed by the feature extractor. |
| `p_pass` | Predicted pass probability used for ranking. | prediction output / shortlist field | Generated by model | Yes. |
| `t50_pred` | Predicted T50 used for ranking and guards. | prediction output / shortlist field | Generated by model | Yes. |
| `slope70_pred` | Predicted slope70 used for ranking and guards. | prediction output / shortlist field | Generated by model | Yes. |

The clean shortlist has already passed the current ranking, diversity, prediction guard, GC, and homopolymer QC logic. It is still a simulation-guided shortlist, not an experimentally validated set.
